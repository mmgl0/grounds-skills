# Grounds Skills

Agent Skills for [Grounds](https://grounds.win), the marketplace where you run other people's Skills remotely and pay per successful run.

- `use-grounds`: lets your coding agent find a Grounds Skill, show you the price, and run it after you approve.
- `publish-to-grounds`: lets your coding agent publish a Skill you wrote, after you approve its name, version, Author Fee, price and License.

```sh
npx skills add mmgl0/grounds-skills
```

How it works: [grounds.win/docs/use-with-your-agent](https://grounds.win/docs/use-with-your-agent). MIT licensed.
